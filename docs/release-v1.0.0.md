# SuperCalc 1.0.0 · 为了计算，先体验

原生 WinUI 3 / C# 计算器，覆盖启动、输入、求值、复制、历史、设置、服务、更新与退出的 30 多种过度设计梗。

## 使用

下载 `SuperCalc-win-x64.zip`，完整解压后启动 `SuperCalc.App.exe`。Windows 11 / Windows 10 2004+ x64，自包含 .NET 与 Windows App SDK。当前发布无签名。

右上角“让我算数”可随时切换专注模式。所有账号、订阅、云、AI 和更新都是本地模拟，不收费、不上传数据。
