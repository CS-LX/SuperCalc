# 验证记录

环境：Windows 11 x64（OS build 26200），.NET SDK 8.0.406，Windows App SDK 1.8.260804001。

## 已执行

- Debug / Release 原生 WinUI 3 构建：零警告、零错误。
- 自包含 Windows x64 发布与启动。
- 发布目录显式包含应用 PRI 资源索引；冒烟脚本同时检查进程退出码。关闭前将焦点移出 TextBox，以规避 [WinUI 已报告的关闭崩溃](https://github.com/microsoft/microsoft-ui-xaml/issues/11653)。
- 50 项核心测试：十进制精度、优先级、右结合幂、百分数、一元负号、平方根、错误输入、除零、溢出、输入边界、小数格式化后重用、本地存储与损坏恢复。
- 18 项应用内集成检查：XAML 加载、求值显示、连续运算、新数字输入、平方、记忆、除零显示、错误恢复、时间线搜索、专注模式、推荐开关、设计博物馆、ContentDialog 加载、本地持久化。
- RenderTargetBitmap 对实际加载的原生 XAML 生成截图，目视检查首页、历史、设置、专注与博物馆；修正 150% DPI 初始尺寸与导航可达性。

## 方法与限制

`--smoke-test <输出目录>` 启动真实应用窗口，使用独立状态路径，调用应用交互处理流程并检查最终可见状态，写入 `results.json` 与 PNG 后退出。它不会改动正常使用的账户、偏好与历史。

桌面自动化工具本次无法启动其 app-server，因此这里的集成检查**不是鼠标 / 键盘注入的端到端测试**。实际人工体验、其他 DPI / 多显示器组合、Windows 10 和干净机器的运行尚未验证。对话框截图单独渲染，因为普通根元素截图不包含 WinUI Popup 层。

功能性注意：平方根是近似值；百分数采用纯数学后缀语义；发布包无代码签名。所有云、AI、订阅和更新流程均为本地模拟。
